# Privacy Policy

**Tapir** does not collect, store, or transmit any personal data.

## Data Collection

- No analytics or tracking
- No network requests
- No user accounts
- No data leaves your device

## Permissions

Tapir requests only **Accessibility** permission, which is required to send keyboard events to other applications via the macOS CGEvent API.
